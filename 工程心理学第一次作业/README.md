# 信号检测论交互实验

本次作业选择了三个判断情境——监考时抓作弊、蛋糕店挑变质蛋糕、车间里查电路故障。玩完一局后，页面会按信号检测论（Signal Detection Theory, SDT）把击中率、误报率、辨别力 d′ 和判断标准等算出来。

## 如何运行

整个项目只有一个 `index.html` 文件，不需要安装任何软件，也不需要启动服务器：

1. 下载或 clone 本仓库；
2. 双击 `index.html`，用 Chrome、Edge 等现代浏览器打开即可。

页面顶部有五个标签：开始 → 场景与参数 → 游戏 → 结果 → 概念实验室，按顺序走即可。

## 场景与信号、噪音的定义

三个场景的信号（S）与噪音（N）定义如下：

| 场景     | 信号 S（有） | 噪音 N（无） | 判断任务     |
| ------ | ------- | ------- | -------- |
| 监考老师   | 学生正在作弊  | 学生正常答题  | 是否报告作弊   |
| 蛋糕店质检员 | 蛋糕已经变质  | 蛋糕新鲜    | 是否判为变质下架 |
| 设备检修工  | 电路存在故障  | 电路运行正常  | 是否判定需要维修 |

游戏开始前可以在"场景与参数"页设定以下参数：

- **先验概率 P(S)**（10%–80%）：出现信号的试次所占的比例；
- **难度 d′**（0.5–3.5）：信号与噪音分布的均值差，也就是两类试次的可分辨程度。d′ 越小，信号和噪音越重叠，越难判断；
- **试次数**（20–120）：每局的判断次数，下限 20 次；
- **刺激限时**（1–5 秒）：每个试次场景画面的呈现时长，倒计时结束后必须做出判断。

## 游戏流程

每个试次的流程是：先呈现一段场景画面，画面里隐藏着强度不等的线索——比如学生会偷看邻座、桌下传纸条、手机透出蓝光；蛋糕颜色发暗、表面塌陷、长出霉点；电路板焦黑、冒烟、打火、指示灯异常发红。线索的强弱由当次试次的证据值决定，信号试次和噪音试次都可能出现弱的线索，需要自己权衡。画面消失后，用二选一按钮判断"有信号/报告"或"无信号/正常"，随后立即给出该次判断属于四种结果中的哪一种。

## 结果与 SDT 计算

一局结束后，结果页给出三部分内容：

1. **混淆矩阵**：统计本局的击中 H、漏报 M、误报（虚报）FA、正确拒斥 CR 四类次数；
2. **四种结果的实际含义**：按你刚玩的场景解释每种结果意味着什么；
3. **SDT 指标**：击中率 P(H)、误报率 P(FA)、辨别力 d′、判断标准 c 和准确率。

计算公式：

- P(H) = 击中 / (击中 + 漏报)
- P(FA) = 误报 / (误报 + 正确拒斥)
- d′ = Z(P(H)) − Z(P(FA))
- c = −0.5 × [Z(P(H)) + Z(P(FA))]

当某类试次全对或全错时，率会取到 0 或 1，Z 分数会趋于无穷。因此计算时采用了 log-linear 校正，即把率改为 (次数 + 0.5) / (该类试次总数 + 1) 再取 Z。

结果页还附了一段"为什么光看准确率不够"的讨论：同样 75% 的准确率，一个只在很确定时才报告的谨慎者和一个稍有可疑就报告的宽松者，d′ 可能完全相同，c 却相反。SDT 的意义正在于把"分辨能力"和"决策倾向"拆开来看。

## 概念实验室

概念实验室里，可以通过拖动 d′、c、P(S) 三个滑块，实现以下内容的实时变化：

- **信号与噪音分布图**：噪音 N(0,1) 与信号 N(d′,1) 两条正态曲线，以及判断标准所在的证据值 xc = −c；
- **ROC 曲线**：当前 d′ 对应的理论受试者工作特征曲线，标注当前 (P(FA), P(H)) 操作点，对角线为纯猜测水平；
- **Z 变换 ROC（zROC）**：横轴 z(FA)、纵轴 z(H)，理论上是斜率约为 1、纵截距为 d′ 的直线；
- **SDT 指标**：d′、c、似然比 β、P(H)、P(FA)、准确率的理论值；
- **混淆矩阵**：当前参数下四种结果的理论概率。

## 多局成绩对比

每局的结果会自动记录，结果页把得到的 d′ 和 c 画成折线，并附明细表（场景、d′、c、P(H)、P(FA)、准确率、试次数），可以观察多局之间辨别力是否稳定、标准是不是越来越松或越来越严。数据只存在浏览器本地，点"清空记录"可以删掉。

## 实现说明

- 使用 HTML + CSS + JavaScript 实现，游戏画面和所有图表均用 Canvas 绘制；
- 正态分布 CDF 用 Abramowitz & Stegun 的误差函数有理近似实现，Z 分数的反函数用 Acklam 的分段有理逼近，随机数用 Box-Muller 变换采样。
